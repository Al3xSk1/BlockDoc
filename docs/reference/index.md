# Reference

A small collection of conventions and quick lookups to keep beside your world.

## Edition and version

The starter content uses **vanilla Java and Bedrock 1.21** as its baseline. When you update an entry, record its tested edition and exact version.

| Label | Meaning |
| :--- | :--- |
| Java | Tested in Minecraft: Java Edition |
| Bedrock | Tested in Minecraft: Bedrock Edition |
| Vanilla | No mods or behavior packs required |

## Commands for a test world

Commands require the appropriate permissions or enabled cheats. Use a separate creative world when checking a recipe or a mechanic.

=== "Java Edition"

    ```mcfunction title="Give yourself a stack of stone"
    /give @s minecraft:stone 64
    ```

=== "Bedrock Edition"

    ```mcfunction title="Give yourself a stack of stone"
    /give @s minecraft:stone 64
    ```

## Using this site

- Open search with ++s++ or the search button. Results include matching page sections.
- Use the top tabs to move between categories and expand nested sidebar branches.
- Switch the color scheme from the header; the initial scheme follows your device.
- Follow the [writing guide](writing.md) to add your own pages.

## External sources

Check changing game details against [Minecraft release notes](https://www.minecraft.net/en-us/articles) and the [community Minecraft Wiki](https://minecraft.wiki/). Link specific sources and record versions when adding detailed mechanics.
