# Redstone

Build reliable circuits by separating three questions: where does power start, how far does it travel, and what should it activate?

## Start here

- [Signal strength](signal-strength.md): power levels, dust, and repeaters.
- [Components](components/index.md): a deeper, collapsible section for individual devices.

## A useful testing setup

Place a lever beside a short line of redstone dust, with a redstone lamp at the far end. Add dust one block at a time and observe when the lamp stops responding.

!!! tip "Label the experiment"
    Record the edition and version beside a screenshot of the circuit. A diagram without that context can be hard to reproduce.
