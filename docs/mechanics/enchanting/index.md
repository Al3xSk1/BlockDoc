# Enchanting

Enchantments specialize your equipment. Start with the job you want the tool to do, then choose its upgrades.

| Goal | Useful enchantment | Consideration |
| :--- | :--- | :--- |
| Mine faster | Efficiency | Use the correct tool for the block |
| Extend tool life | Unbreaking | Durability still decreases over time |
| Repair while collecting XP | Mending | Repairs consume experience |
| Increase eligible drops | Fortune | Does not affect every block |
| Preserve blocks | Silk Touch | Mutually exclusive with Fortune |

## Two useful pickaxes

Keep one [[items/tools/pickaxes|pickaxe]] with Fortune for eligible ores and another with Silk Touch for collecting blocks such as [[blocks/natural/stone|stone]]. Add Efficiency and Unbreaking as resources allow.

> [!tip] Write down exceptions
> When documenting an enchantment, list which blocks it affects and the edition you tested. A precise example is more useful than a broad promise.
