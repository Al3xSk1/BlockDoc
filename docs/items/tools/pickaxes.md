# Pickaxes

Pickaxes harvest stone and ores. The material determines both durability and which resources the tool can collect.

## At a glance

These are base durability values for unenchanted tools in Java and Bedrock 1.21. Mining a suitable block normally costs one durability point.

| Material | Durability | Example harvest capability |
| :--- | ---: | :--- |
| Wood | 59 | Stone and coal ore |
| Stone | 131 | Also iron ore and lapis lazuli ore |
| Iron | 250 | Also diamond ore, gold ore, and redstone ore |
| Gold | 32 | Same harvest tier as wood |
| Diamond | 1,561 | Also obsidian and ancient debris |
| Netherite | 2,031 | Same harvest tier as diamond |

!!! warning "Speed and harvest tier are different"
    A golden pickaxe mines many blocks quickly, but cannot collect diamond ore. Check the required harvest tier before mining a valuable block.

## A practical progression

1. Make a wooden pickaxe to collect your first cobblestone.
2. Switch to stone tools and gather iron.
3. Use an iron pickaxe for diamonds and other higher-tier ores.
4. Reserve a diamond or netherite pickaxe for long mining trips and obsidian.

## Useful enchantments

| Enchantment | Purpose |
| :--- | :--- |
| Efficiency | Improves mining speed |
| Unbreaking | Reduces the chance of durability loss |
| Mending | Repairs the tool using collected experience |
| Fortune | Increases drops from applicable blocks |
| Silk Touch | Collects many blocks in their original form |

Silk Touch and Fortune are mutually exclusive on a normal survival tool. See [enchanting](../../mechanics/enchanting/index.md) and [starter recipes](../../recipes/index.md).
