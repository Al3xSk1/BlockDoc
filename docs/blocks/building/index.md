# Building blocks

A good palette starts with a main material, a contrasting trim, and a small accent.

| Role | Example materials | Use |
| :--- | :--- | :--- |
| Foundation | Stone, cobblestone, stone bricks | Ground a structure visually |
| Main surface | Oak planks, spruce planks | Keep large walls consistent |
| Trim | Stripped logs, stairs, slabs | Frame edges and openings |
| Accent | Mossy cobblestone, leaves | Add occasional texture and color |

!!! tip "Test before you gather"
    Lay out a small wall in a creative world. Check the palette in daylight and inside a lit room before collecting several stacks.

## First palette

Use [[blocks/natural/stone|stone]] as the foundation, oak planks for walls, and stripped oak logs for corners. Add stairs and slabs once the overall shape works.
