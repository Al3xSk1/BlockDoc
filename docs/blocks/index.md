## Reading a block entry

Each block page should record its identifier, preferred tool, drops, and edition or version differences. Separate acquisition from uses so a quick lookup stays quick.

!!! note "Scope"
    These starter entries use vanilla Minecraft 1.21 as their baseline. Record the tested version when expanding an entry.
