# Stone

Stone is a common Overworld block and a dependable starting point for building palettes. Mining it normally produces cobblestone.

| Property | Value |
| :--- | :--- |
| Identifier | `minecraft:stone` |
| Stack size | 64 |
| Hardness | 1.5 |
| Blast resistance | 6 |
| Required tool for drops | Any pickaxe |
| Normal drop | Cobblestone |
| With Silk Touch | Stone |
| Example baseline | Java & Bedrock 1.21 |

## Obtaining

- Mine stone with a [[items/tools/pickaxes|pickaxe]] to collect cobblestone.
- Smelt cobblestone in a furnace to turn it into stone.
- Mine stone with a Silk Touch pickaxe to collect it directly.

!!! warning "Bring a pickaxe"
    Breaking stone without a suitable tool produces no item drop.

## Uses

Stone works well in neutral builds and can be crafted into stone bricks. Smelting stone again produces smooth stone.

??? tip "Build with a little texture"
    Mix stone, cobblestone, and stone bricks in small groups. Repeating a few related textures adds depth while keeping the palette calm.
