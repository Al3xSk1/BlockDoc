# Recipes

Essential recipes for the first few sessions. These examples target vanilla Java and Bedrock 1.21.

## Starter crafting

| Output | Ingredients | Crafting area |
| :--- | :--- | :--- |
| 4 planks | 1 matching log | Inventory or crafting table |
| 4 sticks | 2 planks, stacked vertically | Inventory or crafting table |
| Crafting table | 4 planks in a 2 x 2 square | Inventory or crafting table |
| Wooden pickaxe | 3 planks + 2 sticks | Crafting table |
| Stone pickaxe | 3 cobblestone + 2 sticks | Crafting table |
| Furnace | 8 cobblestone, with the center empty | Crafting table |
| 4 torches | 1 coal or charcoal above 1 stick | Inventory or crafting table |

## Pickaxe pattern

Use planks for a wooden pickaxe, cobblestone for a stone pickaxe, or the appropriate other crafting ingredient. Netherite upgrades use a smithing table instead.

| | | |
| :---: | :---: | :---: |
| Material | Material | Material |
| Empty | Stick | Empty |
| Empty | Stick | Empty |

## Smelting

| Input | Output | Equipment |
| :--- | :--- | :--- |
| Cobblestone | Stone | Furnace + fuel |
| Stone | Smooth stone | Furnace + fuel |
| Log | Charcoal | Furnace + fuel |
| Raw iron | Iron ingot | Furnace or blast furnace + fuel |

!!! note "Fuel is a separate input"
    Smelting recipes require fuel as well as an ingredient. A piece of coal or charcoal fuels eight smelts in a regular furnace.
